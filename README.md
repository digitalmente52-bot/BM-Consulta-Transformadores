# BM Consulta de Transformadores

Aplicación web para la consulta de información de **transformadores y
seccionadores**.

## Descripción

BM Consulta de Transformadores reúne en una interfaz web herramientas de
consulta relacionadas con transformadores y seccionadores.

Este repositorio contiene el archivo principal de la aplicación:

-   `index.html`: archivo HTML de la aplicación.

## Objetivo

Facilitar el acceso a la aplicación desde un navegador web y permitir
que el proyecto se mantenga y actualice mediante GitHub.

## Cómo abrir la aplicación

Cuando la aplicación esté publicada mediante GitHub Pages, se podrá
abrir desde el enlace público que GitHub genere para este repositorio.

Mientras tanto, también es posible abrir el archivo `index.html`
localmente en un navegador compatible.
